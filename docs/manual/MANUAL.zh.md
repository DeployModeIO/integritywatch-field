# IntegrityWatch Field — 用户手册

**本手册适用于：** 场站操作员、完整性工程师、维护与运营主管。无需编程知识。应用程序**完全离线运行**，您的数据不会离开您的电脑。

---

## 1. 安装并打开应用程序

### Windows（便携版）
1. 从 GitHub Releases 下载 `IntegrityWatch-Field-Portable.part1.rar` 和 `part2.rar`。
2. 将所有文件放入同一文件夹，并使用 WinRAR 或 7-Zip 解压。
3. 双击 `START-HERE.bat`。本地服务器启动，浏览器自动打开应用程序。
4. 应用程序也可直接从 U 盘运行。无需安装，无需管理员权限。

### macOS
1. 解压包后双击 `START-HERE.command`。
2. 浏览器会自动打开 `http://localhost:8419`。

### Linux
1. 解压包后双击 `start.sh`（或运行 `./start.sh`）。
2. 浏览器会自动打开 `http://localhost:8419`。

### 作为应用安装（PWA）——推荐日常使用
1. 使用 `START-HERE.bat` 启动应用。
2. 在浏览器地址栏点击 **安装** 按钮（或菜单 ⋮ → “安装应用”）。
3. 从此以后，您可以直接从应用图标打开，且完全离线运行。

**要求：** Chrome、Edge、Firefox 或 Safari（最近两年版本）。最小屏幕分辨率 1366×768。支持平板和手机。

## 2. 首次启动（5 分钟）

1. 应用程序加载时会显示**演示数据**：8 个腐蚀点、5 个阀门、1 条管线（含 12 个资产）、9 个 APM 资产，以及约 120 条读数。这可以验证所有界面功能正常。
2. 在页面顶部选择您的语言：英语、西班牙语、法语、葡萄牙语、简体中文、俄语、阿拉伯语。阿拉伯语会将界面整体切换为从右到左布局。
3. 选择您的主题：☀️/🌙/🖥️ 按钮可循环切换为亮色 → 深色 → 自动模式。您的选择会自动保存。
4. 使用**区域筛选**（全部 / 上游 / 中游 / 下游）来过滤仪表盘和 APM 展示内容。

> 若想从头开始使用自己的数据，请在菜单中选择 **管理 → 重置演示数据**（或清除全部）。

---

## 3. 腐蚀监测

1. **创建监测点**：腐蚀 → “新建点”。填写编号（例如：MP-CORR-021）、材料（13 种钢材及合金）、传感器类型（试片、ER、LPR、H₂S 探头、UT、视觉）、工艺数据（H₂S、CO₂、压力、温度、BS&W、流速、抑制剂目标值和残留量）。如适用，添加阴极保护和 CUI 绝缘。
2. **记录读数**：打开该点 → “新增读数” → 填写日期 + 腐蚀速率（mpy）+ 备注。
3. **记录试片数据（抑制剂/空白对）**：点击“新建试片” → 选择 **角色**（空白或受抑制）和 **对号**（例如：P3）→ 输入初始重量、最终重量、面积和天数。系统自动计算腐蚀速率（依据 ASTM G1/G4）。**抑制剂效率面板** 比较两组试片并给出评级（优秀 ≥90%，差 <70%）。
4. **自动面板**：抑制剂平衡（80–150% 范围）、De Waard–Milliams 模型对比实测值、NACE MR0175（pH₂S）酸性环境筛查、阴极保护和 CUI 检查。
5. **点位报告**：点击“点位报告”按钮，可生成可打印的单页报告，每页对应一个监测点。

---

## 4. 安全泄压阀（PSV）

1. **注册阀门**：点击“新建 PSV” → 输入标签、类型（常规 / 平衡波纹 / 压力先导）、流体（11 种预设，可编辑）、设定压力、温度、背压和测试日期。
2. **进行尺寸计算**：打开阀门 → 切换到 **气体** 和 **液体** 标签页：
   - 气体：流量 W、压力/温度、Z、M、k → 根据 API 520 计算所需面积。应用可识别临界或亚临界流动。
   - 液体：流量 Q、重力 G、粘度 → 使用 Kv 粘度修正计算面积。
   - 应用会**自动选择 API 526 阀口**（D–T），并显示安全裕量和实际容量。
3. **保存尺寸数据**，并打印 **数据表**（API 520 / ISA 格式）。

---

## 5. 管线（中游）

1. **创建系统**：输入名称、运营商、产品、直径、壁厚、材料、长度和站点范围（公里）。
2. **添加管线资产**：在系统内点击“新建管线资产” → 选择类型（12 种：阀门、法兰、泵站/压缩机站、储罐、穿越、行线权、计量点等）、站点公里数和侧边。
3. **记录检查**：选择检查类型（ILI、外部腐蚀、视觉、UT、修复、更换）、公里段、严重程度、发现情况。
4. **地图显示**：在管线沿线按公里比例绘制节点，颜色根据最近一次检查的严重程度区分。支持键盘导航（Tab 和 Enter）。

---

## 6. 资产性能（APM）

1. **创建资产**：填写编号、名称、所属区域、类别（井、平台、泵、压缩机、换热器、塔、公用设施等）、重要性等级 A/B/C，以及 **POF × COF** 风险值（RBI 风险模型）。系统会根据风险等级建议下次检查日期。
2. **记录事件**：包括故障、维护、非计划停机、工作单或检查，填写日期和停机时间。系统自动计算 **可用性、MTBF 和 MTTR**，并显示健康状态的红黄绿灯。
3. **5×5 风险矩阵** 显示每个资产的风险位置，并确定其检查优先级。

---

## 7. 导入您的数据（CSV、WITSML、JSON）

1. 进入 **CSV** 标签页 → “选择文件”（或拖拽文件上传）。支持逗号、分号或制表符分隔的文件。
2. 检查**列映射**——应用会自动识别点位、日期、速率、初始重量 Wi、最终重量 Wf、面积、天数、残留量、温度、BSW、类别、备注等字段。支持西班牙语和英语字段名。
3. 若文件包含新监测点，请勾选 **“创建缺失点”**。
4. **运行校验** → 错误表会列出问题行（如未来日期、Wf > Wi、超出范围、未知点、重复项被跳过）。若更改勾选框，需重新校验后导入。
5. **导入** → 显示导入摘要，操作记录保存在历史中。
6. 额外标签页：**WITSML**（井、轨迹、通道）和 **JSON**（完整备份，支持合并或覆盖模式）。

---

## 8. 规则与建议

- 点击 **运行规则**（顶部按钮）来扫描所有数据。应用内置 17 条工程规则（R1–R17）：壁厚损耗、点蚀、PSV 检查超期、抑制剂问题、管线缺陷、APM 风险变化。
- 每条建议均显示规则名称、实际数值、影响的资产以及指向其记录的链接。
- 操作流程：**确认** → **解决**（附带说明）。所有操作均带时间戳和操作人信息。
- 若问题在解决后再次出现，建议将**自动重新打开**。

---

## 9. 报告

1. **季度报告**：选择时间段 → 生成 → 包含封面页、KPI 指标、周度趋势图、最严重点、试片效率、检查活动及待办建议。点击 **打印** → “另存为 PDF”。
2. **点位报告**：包含技术说明、历史记录、ASTM G1/G4 计算、NACE SP0775 分类、MR0175 酸性环境筛查。
3. **阀门数据表**：完整尺寸计算表，可复制到剪贴板。

---

## 10. 数据备份

1. 进入 **管理 → 导出**，生成一个包含全部数据的 JSON 文件。保存到网络或 U 盘。
2. **恢复数据**：进入“导入” → JSON 标签页 → 选择文件 → 选择模式：**合并**（新增）或 **覆盖**（完全恢复）。
3. 每周备份一次，每次大规模导入前务必进行备份。

## 11. 快速操作指南

| 您想…… | 操作方式 |
|--------|---------|
| 加载月度试片检查计划 | 导入 → CSV → 选择文件 → 校验 → 导入 → 分配角色/配对 → 运行规则 → 查看建议 |

## 12. 常见问题排查

| 症状 | 可能原因 | 解决方法 |
|------|--------|--------|
| 启动时提示“端口占用” | 另一个程序占用了端口 8419 | 运行 `tools\serve.ps1 -Port 9000`，或关闭其他程序 |
| PowerShell 阻止脚本执行 | 执行策略限制 | 使用 `START-HERE.bat`（已包含绕过设置），或运行 `py tools\serve.py` |
| 无“安装应用”按钮 | 直接从磁盘打开 `index.html` | 必须使用 `START-HERE.bat` 启动（PWA 需要 `http://localhost`） |
| 数据丢失 | 使用了隐私/无痕模式，或清除网站数据 | 从 JSON 备份恢复；避免使用隐私模式 |
| 显示“有更新可用”提示 | 发布了新版本 | 点击提示栏中的 **刷新** 按钮 |
| 仍显示旧版本 | 服务工作线程缓存 | 点击 **刷新**，或按 Ctrl+F5，或打开开发者工具 → 应用程序 → 服务工作线程 → 更新 |
