# IntegrityWatch Field — Руководство для пользователя

**Кому это руководство предназначено:** операторам месторождений, инженерам по целостности, руководителям технического и эксплуатационного персонала. Нет необходимости в знаниях программирования. Программа работает **100% без подключения к интернету**. Ваши данные никогда не выходят за пределы вашего компьютера.

---

## 1. Установка и запуск приложения

### Windows (портативная версия)
1. Скачайте `IntegrityWatch-Field-Portable.part1.rar` и `part2.rar` из раздела GitHub Releases.
2. Разместите все части в одной папке и распакуйте с помощью WinRAR или 7-Zip.
3. Дважды щелкните `START-HERE.bat`. Запускается локальный сервер и открывается браузер с приложением.
4. Приложение также может работать с флеш-накопителя. Не требуется установка, не требуется права администратора.

### macOS
1. Распакуйте пакет и дважды щелкните `START-HERE.command`.
2. В браузере откроется `http://localhost:8419`.

### Linux
1. Распакуйте пакет и дважды щелкните `start.sh` (или выполните `./start.sh`).
2. В браузере откроется `http://localhost:8419`.

### Установка в виде приложения (PWA) — рекомендуется для ежедневного использования
1. Запустите приложение с помощью `START-HERE.bat`.
2. В строке адреса браузера нажмите кнопку **Install** (или в меню ⋮ → "Install app").
3. С этого момента приложение запускается из собственного иконки и работает полностью без подключения к интернету.

**Требования:** Chrome, Edge, Firefox или Safari (последние 2 года). Минимальный размер экрана — 1366×768. Работает на планшетах и смартфонах.

## 2. Первый запуск (5 минут)

1. Приложение загружается с **примерными данными**: 8 точек коррозии, 5 клапанов, одна трубопроводная линия с 12 активами, 9 активов APM и около 120 измерений. Это показывает, как работают все экраны.
2. **Выберите язык** в верхней части экрана: English, Español, Français, Português, 简体中文, Русский, العربية. При выборе арабского языка весь интерфейс переходит в правый формат.
3. **Выберите тему**: кнопки ☀/🌙/🖥 переключают светлую, тёмную и автоматическую тему. Ваш выбор сохраняется.
4. **Фильтр сектора** (All / Upstream / Midstream / Downstream) фильтрует Дашборд и APM.

> Чтобы начать с чистых данных: в меню **Admin → Reset demo data** (или удалить все).

---

## 3. Мониторинг коррозии

1. **Создайте точку мониторинга:** Коррозия → "New point". Заполните код (пример: MP-CORR-021), материал (13 сталей и сплавов), тип датчика (coupon, ER, LPR, H₂S-датчик, UT, визуальный) и данные процесса (H₂S, CO₂, давление, температура, BS&W, скорость, целевой уровень ингибитора и остаток). Добавьте данные о катодной защите и изоляции CUI, если они применимы.
2. **Запишите измерения:** откройте точку → "New reading" → дата + скорость (mpy) + примечание.
3. **Запишите купоны (пары ингибитора/пустого):** "New coupon" → выберите **Роль** (Blank или Inhibited) и **Пару** (пример: P3), затем начальный и конечный вес, площадь и количество дней. Скорость коррозии рассчитывается автоматически (ASTM G1/G4). В панели **Эффективность ингибитора** сравниваются оба купона и оценивается результат (Отлично ≥90%, Плохо <70%).
4. **Автоматические панели:** баланс ингибитора (диапазон 80–150%), модель De Waard–Milliams по сравнению с измеренными значениями, сортировка в условиях кислоты NACE MR0175 (pH₂S), катодная защита и CUI.
5. **Досье точки:** кнопка "Point dossier" создаёт печатный отчёт — один лист на каждую точку мониторинга.

---

## 4. Манометрические клапаны (PSV)

1. **Зарегистрируйте клапан:** "New PSV" → метка, тип (традиционный / баллонный / пилотный), жидкость (11 предустановленных, редактируемых), установочное давление, температура, обратное давление и даты проверок.
2. **Размерьте клапан:** откройте клапан → вкладки **Gas** и **Liquid**:
   - Gas: расход W, давление/температура, Z, M, k → требуемая площадь по API 520. Программа определяет критический или подкритический поток.
   - Liquid: расход Q, гравитация G, вязкость → площадь с коррекцией по вязкости Kv.
   - Программа **автоматически выбирает орфис API 526** (D–T) и показывает запас и реальную производительность.
3. **Сохраните размеры** на клапане и распечатайте **данные по техническому паспорту** (форматы API 520 / ISA).

---

## 5. Трубопроводы (средний участок)

1. **Создайте систему:** название, оператор, продукт, диаметр, толщина стенки, материал, длина и диапазон станций (км).
2. **Линейные активы:** внутри системы, "New line asset" → тип (12 видов: клапаны, фланцы, станции насосов и компрессоров, баки, пересечения, ROW, измерительные устройства…), км станции и сторона.
3. **Инспекции:** тип (ILI, внешняя коррозия, визуальный, UT, ремонт, замена), сечение км, степень серьезности, результаты.
4. **Карта:** узлы отображаются на линии в масштабе км, цвета соответствуют степени серьезности последней инспекции. Навигация по клавишам (Tab и Enter).

---

## 6. Производительность активов (APM)

1. **Создайте актив:** код, название, сектор, категория (скважины, платформы, насосы, компрессоры, теплообменники, башни, инженерные системы…), критичность A/B/C и **POF × COF** риск (по методу RBI). Дата следующего осмотра предсказывается на основе уровня риска.
2. **Запись событий:** отказ, техническое обслуживание, непланируемое отключение, заказ на работу или инспекцию с датами и временем простоя. Программа рассчитывает **доступность, MTBF и MTTR** и показывает индикатор состояния (сигналы красного, жёлтого, зелёного).
3. **Матрица риска 5×5** показывает, где находится каждый актив и какова его приоритет инспекции.

---

## 7. Импорт ваших данных (CSV, WITSML, JSON)

1. Вкладка **CSV** → "Choose file" (или перетащите файл). Поддерживает файлы, разделённые запятыми, точками или табуляцией.
2. Проверьте **сопоставление столбцов** — программа автоматически определяет точку, дату, скорость, Wi, Wf, площадь, дни, остаток, температуру, bsw, категорию, примечание. Принимаются заголовки на английском и испанском.
3. Поставьте галочку **"Создать отсутствующие точки"**, если в файле есть новые точки мониторинга.
4. **Запустите проверку** — в таблице ошибок указаны плохие строки (дата в будущем, Wf больше Wi, выход за пределы диапазона, неизвестная точка, дубликаты пропускаются). Если вы измените флажок, выполните проверку повторно перед импортом.
5. **Импортируйте** — появляется сводка, и действие записывается в историю.
6. Дополнительные вкладки: **WITSML** (скважины, траектории, каналы) и **JSON** (полная резервная копия, режим слияния или замены).

## 8. Правила и рекомендации

- Нажмите **Run rules** (кнопка в верхней части экрана), чтобы сканировать всё. Программа содержит 17 инженерных правил (R1–R17): скорости потери стенки, кавитация, просроченные проверки PSV, проблемы с ингибиторами, результаты трубопроводов и изменения риска APM.
- Каждая рекомендация показывает правило, реальные значения, затронутый актив и ссылку на его запись.
- Действия: **Подтвердить** → **Решить** (с примечанием). Все действия помечаются датой и пользователем.
- Если условие возникает снова после решения, рекомендация **автоматически переоткрывается**.

---

## 9. Отчёты

1. **Квартальный отчёт:** выберите период → Generate → обложка, KPI, график по неделям, самые опасные точки, эффективность пар, кампании и открытые рекомендации. Кнопка **Print** → "Сохранить как PDF".
2. **Досье точки:** технический лист + история + расчёты ASTM G1/G4 + классификация SP0775 + сортировка MR0175.
3. **Технический паспорт клапана:** полный расчётный лист, копируется в буфер обмена.

---

## 10. Резервные копии

1. **Admin → Export** создаёт один JSON-файл со всеми вашими данными. Сохраните его на сети или флеш-накопителе.
2. **Восстановление:** вкладка Ingestion → JSON → выберите файл → режим **merge** (добавление) или **replace** (полное восстановление).
3. Резервируйте данные **еженедельно** и всегда перед крупным импортом.

## 11. Быстрые рецепты

| Что вы хотите… | Что делать |
|---|---|
| Загрузить месячную кампанию купонов | Ingestion → CSV → файл → проверка → импорт → назначить Role/Pair → Run rules → проверить рекомендации |
| Программировать инспекцию по методу RBI | APM → актив → настроить POF/COF → пересчитать дату следующего осмотра (дата следует за уровнем риска) |
| Распечатать квартальный отчёт | Reports → Quarterly → даты → Generate → Print → PDF |
| Перенести данные на второй ноутбук | Admin → Export → скопировать JSON → на другом ноутбуке: Ingestion → JSON → merge |

## 12. Устранение неполадок

| Симптом | Вероятная причина | Решение |
|---|---|---|
| "Порт занят" при запуске START-HERE | Другой процесс использует порт 8419 | Запустите `tools\serve.ps1 -Port 9000`, или закройте другой процесс |
| PowerShell блокирует скрипт | Политика выполнения | Используйте `START-HERE.bat` (он уже содержит обход), или `py tools\serve.py` |
| Нет кнопки "Установить приложение" | Вы открыли `index.html` из диска | Запускайте с `START-HERE.bat` (PWA требует `http://localhost`) |
| Данные исчезли | Работа в приватном режиме или удаление данных сайта | Восстановите JSON-резервную копию; избегайте приватного режима |
| Появляется баннер "Обновление доступно" | Новая версия была выпущена | Нажмите **Reload** на баннере |
| Показывается старая версия | Кэш сервис-работников | Нажмите **Reload**, или нажмите Ctrl+F5, или в DevTools → Application → Service Workers → Update |

## 13. Важные замечания

- IntegrityWatch Field — это **инструмент поддержки**. Он не заменяет профессиональное мнение квалифицированного инженера.
- Все расчёты необходимо проверять по актуальной версии соответствующих стандартов (API 510/570/653, ASME PCC-2, NACE SP0775/MR0175, ASTM G1/G4) и данным производителя перед любыми операционными решениями.
- Лицензия MIT. Бесплатно использовать, копировать и модифицировать. Ссылка на репозиторий: см. репозиторий этого проекта.
